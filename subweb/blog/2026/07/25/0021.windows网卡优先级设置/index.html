在实验室使用电脑时，我们有时会同时连接网线和 Wi-Fi，以满足不同的网络使用需求。

一般情况下，很多人会认为：只要插上网线，Windows 就一定会优先使用有线网络。但实际使用中并不总是如此。有些电脑会优先走有线，有些电脑却仍然通过 Wi-Fi 上网。

这是因为 Windows 选择网络出口时，并不是单纯根据“有没有插网线”来判断，而是根据网络接口的跃点数，也就是 Metric，决定哪张网卡的优先级更高。

本文记录一下 Windows 10 中设置有线网络优先的方法。

一、Windows 如何决定使用哪张网卡？

当有线网卡和无线网卡同时连接时，两张网卡通常都会获得：

  • IP 地址
  • 默认网关
  • DNS 服务器
  • 默认路由

Windows 会比较不同网络接口的路由成本。

当网线断开后，以太网对应的路由失效，系统会自动切换到 Wi-Fi，因此不需要每次手动关闭无线网络。

二、为什么不同电脑的优先网络不一样？

不同电脑可能出现不同结果，常见原因包括：

  1. 网卡协商速度不同
  2. 网卡驱动设置不同
  3. Windows 自动分配的 Metric 不同
  4. 有线网络只协商到 10 Mbps 或 100 Mbps
  5. Wi-Fi 连接速度高于有线连接
  6. VPN、虚拟网卡或安全软件修改了路由
  7. IPv4 和 IPv6 的接口优先级不同

因此，即使两台电脑连接的是同一个路由器，它们的网络出口也可能不一样。

十、常见问题

1. 设置有线优先后，Wi-Fi 还需要关闭吗？

不需要。

Wi-Fi 可以继续保持连接。有线网络正常时，默认流量优先走有线；拔掉网线后，系统会自动切换到 Wi-Fi。

这也是同时保留两种连接的主要好处。

2. 两张网卡连接同一个路由器，会不会网速叠加？

通常不会。

普通 Windows 网络连接不会自动把有线和 Wi-Fi 的带宽合并。即使两张网卡同时连接，单个普通网络连接通常仍然只会选择其中一条路径。

要实现多线路聚合，需要路由器、服务器、驱动程序或特定软件的支持，不能仅靠调整 Metric 实现。

3. 为什么设置后某些访问仍然走 Wi-Fi？

可能原因包括：

  • 目标地址存在更具体的静态路由
  • VPN 添加了新的路由
  • IPv4 和 IPv6 设置不一致
  • 两张网卡连接了不同子网
  • 应用程序主动绑定了某个网络接口
  • 虚拟机或安全软件修改了路由表

系统选择路由时，会优先匹配更具体的路由，然后才比较 Metric。

因此，“有线优先”主要控制默认网络出口，并不意味着所有流量都必须经过有线网卡。

4. 为什么设置 Metric 后仍然没有变化？

可以依次检查：

  1. PowerShell 是否以管理员身份运行
  2. 设置的 ifIndex 是否正确
  3. 有线和无线是否都处于 Connected 状态
  4. IPv4 和 IPv6 是否都已设置
  5. 是否存在 VPN 或虚拟网卡
  6. 默认路由是否指向正确网关
  7. 网卡是否需要重新连接或重启
